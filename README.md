# 💰 SmartMoneyManager

🚀 A responsive full-stack finance management web application designed to help users track income, expenses, budgeting, and financial goals with an interactive and user-friendly interface.

---

## ✨ Features

- 💵 Income & Expense Tracking
- 📊 Financial Analytics Dashboard
- 📅 Budget Planning & Management
- 🎯 Goal Tracking
- 🔐 Secure Authentication
- 📈 Spending Insights
- 🤖 AI-Powered Financial Suggestions
- 🌙 Modern Responsive UI

---

## 🛠️ Tech Stack

### Frontend
- ⚛️ React.js
- 🎨 Tailwind CSS
- 📊 Recharts

### Backend
- ☕ Spring Boot
- 🔐 Spring Security
- 🛢️ MongoDB

---

## 🚀 Installation

### 📌 Frontend

```bash
cd app
npm install
npm run dev
```

### 📌 Backend

```bash
cd money-manager/backend
mvn spring-boot:run
```
